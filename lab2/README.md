Лбораторный практикум №2
## Состав проекта

- `Part1_Interfaces` — задания по интерфейсам, полиморфизму и принципу ISP.
- `Part2_Repository` — Repository, Generic Repository, асинхронные методы и Unit of Work с Entity Framework Core.
- `Part3_UserApi` — REST API для сущности User с JSON и CRUD.
- `database.sql` — создание базы `delivery_db` и основных таблиц.
- `LaboratoryWork2.sln` — решение Visual Studio.

## Требования

- .NET 8 SDK
- Visual Studio 2022 или JetBrains Rider
- MySQL 8.x
- Git
